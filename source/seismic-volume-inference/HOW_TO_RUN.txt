Volume-level test inference
===========================

Copy these 3 files into the `source/` folder of the repo:

  volume_inference.py
  run_3d_test.py
  test_volume_reconstruction.py

1) Check reconstruction (no GPU, no data):

   python source/test_volume_reconstruction.py

2) Run the real test (Colab / local, with your checkpoint and test.h5):

   python source/run_3d_test.py \
     --checkpoint /path/to/best_checkpoint.pytorch \
     --h5 /path/to/temp_splits/spatial/test.h5 \
     --config /path/to/my_configs/generated_config.yaml \
     --save_volume \
     --output_dir test_logs_volume

Official baseline = VOLUME-LEVEL mean IoU without background
(printed at the end, also in metrics.json -> volume_level.mean_iou_no_background).

Do NOT try to match the old 56.6% patch-level number.

Training code is unchanged.
