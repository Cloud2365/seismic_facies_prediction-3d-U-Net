# Исправления по итогам ревью

## Ошибки

1. `RandomFlip` отражал патч по глубине (оси `(1, 2)` при порядке `(crossline, depth, inline)`). Теперь оси `(0, 2)`. Глубина больше не отражается; тест `test_random_flip_never_flips_depth` падает на старом коде.
2. Нормализация min-max считалась по каждому патчу. Теперь по умолчанию (`--norm global`) диапазон амплитуд — перцентили 0.5/99.5 по train, одинаковый для train/val/test и записанный в конфиг. Старый режим доступен через `--norm patch`.
3. `LazyHDF5DatasetWithDepth`: нормализация вынесена в обычный `raw`-трансформер, канал глубины добавляется после трансформаций (раньше поворот `RandomRotate` поворачивал и канал глубины). Тестовый файл больше не открывается на запись. Старые конфиги без `Normalize` работают с прежней нормализацией по патчу.
4. `--early_stop` объявлялся, но не использовался. Теперь передаётся в тренер как `patience`; `0` отключает. Тренер также останавливается, если LR падает ниже `1e-6` (`should_stop` раньше не вызывался).
5. Обучение писало `generated_config.yaml`, а тест читал `generated_config_spatial.yaml`. Теперь конфиг называется `generated_config_<split>.yaml`, его копия кладётся в папку чекпоинта.
6. `run_3d_test.py`: патч, шаг, число классов, трансформации и наличие канала глубины берутся из конфига (раньше `[16,128,128]`/`[8,64,64]` были вписаны в четырёх местах, `Normalize` — вручную). Батчевый инференс с собственным `collate_fn`. Ширина полосы для boundary-метрик уменьшается для тонких патчей.
7. `diagnose_baseline.py`: mIoU больше не константа `0.58842`, а считается по тем объёмам, которые диагностируются; в сводку добавлены pixel accuracy и статистика перекрытий.
8. `convert_to_h5.py`: пути через аргументы вместо `E:\...`; ошибка чтения среза теперь останавливает сборку (раньше срез молча пропускался и сдвигал индексы split); предупреждения о срезах без пары и пропусках номеров.
9. `.gitignore`: не исключает отслеживаемую `source/baseline_diagnostics/`; игнорируются все `generated_config*.yaml`.

## Добавлено

- `source/monotonic_decode.py` и флаг `--monotonic` в тесте: неубывающая по глубине разметка (динамическое программирование), метрики печатаются для обоих вариантов.
- `source/tests/`: 11 тестов (склейка, монотонное декодирование, флип, датасет с глубиной, ранняя остановка).

## Что меняет результаты

Значения по умолчанию `--norm global` и исправленный флип меняют обучение. Чтобы воспроизвести прежние 0.641, запускайте с `--norm patch` (без `--aug`). `--early_stop 10` теперь действительно работает и может завершить обучение раньше 50 эпох; лучший чекпоинт от этого не меняется. Цифру 0.634 с `--aug` нужно пересчитать.
